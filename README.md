
📊 Dashboard: Controle de Perdas de Produção

Este projeto consiste em um dashboard desenvolvido no Power BI com o objetivo de monitorar, analisar e mitigar os desperdícios e ineficiências dentro do processo produtivo. Ele consolida indicadores essenciais para dar suporte à tomada de decisões estratégicas na gestão industrial e de operações.

🎯 Indicadores e Análises Chave

• Evolução do Volume de Perdas: Gráficos temporais para identificar tendências de desperdício ao longo dos turnos, dias ou meses.

• Análise por Categoria / Motivo: Classificação detalhada das causas das perdas (ex: quebras de maquinário, falhas operacionais, problemas de qualidade da matéria-prima, setups de linha).

• Impacto Financeiro: Tradução das perdas físicas (unidades, kg, metros) em valores monetários para mensurar o real impacto no custo de fabricação.

• Pareto de Ineficiência: Visões focadas nos "gargalos" que representam a maior fatia do desperdício, permitindo focar os planos de ação onde haverá maior retorno.
